# Claw AI - Android Client (WebView & PWA)

## Вариант 1: Быстрая установка PWA на Android (Рекомендуется, 0 секунд сборки)
Приложение полностью поддерживает стандарт Progressive Web App (PWA).
1. Откройте веб-адрес приложения в браузере Chrome на Android телефоне.
2. Нажмите появившуюся кнопку **«Установить на Android»** в боковом меню приложения (или в меню браузера Chrome нажмите «Добавить на главный экран» / «Установить приложение»).
3. Приложение установится на рабочий стол Android как полноценное отдельное приложение без рамок браузера, с полноэкранным запуском, иконкой и локальным кэшированием.

## Вариант 2: Сборка нативного APK (Android Studio)
В этой папке находится проект Android WebView приложения:
1. Откройте директорию `android/` в Android Studio.
2. В файле `MainActivity.kt` укажите публичный URL вашего развернутого сервера в переменной `appUrl`.
3. Нажмите `Build -> Build Bundle(s) / APK(s) -> Build APK(s)`.
4. Полученный `.apk` файл устанавливается на любой Android смартфон.
